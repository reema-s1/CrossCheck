# Nimbus Diagnostics

Nimbus Diagnostics checks your device's hardware for problems, including the battery, display, speakers, microphones, cameras, sensors, and wireless connectivity.

To run diagnostics on a Nimbus Phone X2, go to Settings > Privacy > Analytics > Nimbus Diagnostics, or a Nimbus Support agent can send a diagnostics request to your phone. On a Nimbus Laptop Air, shut down the laptop, then press and hold the power button until you see "Loading startup options," and press Command-D.

Diagnostics takes 2 to 5 minutes. When complete, you'll see a reference code; codes starting with "PPT" indicate a battery issue, and codes starting with "NDC" indicate a wireless connectivity issue. Share the reference code with Nimbus Support. Diagnostics does not collect personal data.
